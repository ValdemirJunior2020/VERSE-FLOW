VERSEFLOW - LYRICS + LOCAL INTERNET AGENT UPDATE
Date: 2026-08-29

Architecture used
- Ollama: local reasoning/default AI. No OpenAI requirement added.
- Panniantong/Agent-Reach: internet access setup/health/router layer. VerseFlow uses the Exa search bridge installed/configured by Agent-Reach.
- unclecode/crawl4ai: optional clean webpage extraction through a fixed, read-only Python call.
- browser-use/browser-use: installed/status-ready as an optional browser fallback; normal song search does not depend on browser automation.

Collection repos confirmed present
- Panniantong/Agent-Reach
- unclecode/crawl4ai
- browser-use/browser-use
- ItzCrazyKns/Perplexica
- firecrawl/firecrawl
- NousResearch/hermes-agent
- FoundationAgents/OpenManus

Not wired into VerseFlow runtime
- Perplexica, Firecrawl, Hermes Agent, OpenManus. They overlap the chosen layers and would add unnecessary services/dependencies for this focused feature.

Major additions
- New main sidebar LYRICS section.
- Search Lyrics / My Lyrics / Modern-Licensed / Public Domain / Create Your Own / Create Original With Ollama.
- Local-first fuzzy song matching, then Agent-Reach internet search.
- Internet result provenance: source title, source URL, retrieval date, confidence, rights classification.
- Copyright-safe modern-song flow: no automatic permanent scraping/storage of modern lyrics.
- Authorized local lyrics text/JSON import.
- Structured section editor with duplicate/delete/move/rename and section add controls.
- Ollama organizer that rejects results if lyric wording changes.
- Ollama original worship-song generation marked Original / AI Assisted.
- Presentation-ready lyric slides with max 4 lines, section labels, Preview/Live/Next/Previous, and entire-song service insertion.
- Smart Presenter lyric actions: find song, show section, repeat/show chorus/bridge/verse, next lyrics, previous lyrics.
- Settings Internet Agent status and Windows installer.
- Prompt-injection guardrails: web content is treated as untrusted data; URLs are validated; website text cannot become shell commands or filesystem actions.

Offline behavior
- Lyrics editor and saved lyrics remain local.
- Internet search reports local-only fallback when unavailable.
- Bundled Amazing Grace starter is explicitly marked Public Domain.
