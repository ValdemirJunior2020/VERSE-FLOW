# Full Offline Bibles

This build includes the complete Genesis-to-Revelation Bible files supplied by the user.

They are stored under `bibles/bundled/` and can be installed from VerseFlow's Bible Library without internet access.

Partial-canon files from the supplied packs are not registered as full-Bible installs:
- Tyndale Bible export (33 books)
- Reina Valera 1858 NT (27 books)
- WLC Hebrew Bible / Tanakh (39 books)

The Strong's editions are included as separate full translations because their supplied exports contain all 66 books.
