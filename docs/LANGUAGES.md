# VerseFlow Languages

- English is the default UI language.
- Click the **United States flag** for English.
- Click the **Brazilian flag** for Brazilian Portuguese (`pt-BR`).
- Click the **Spanish flag** for Spanish.
- The selected UI language is saved locally and restored next time VerseFlow opens.

The language switch changes VerseFlow interface labels only. It never translates, paraphrases or edits Bible text, worship-song lyrics, imported media, or operator-entered content. Use the Bible translation selector to choose Scripture language/version.
