# Windows Release Checklist

- Tests pass.
- Bible sample is clearly labeled development-only.
- Audience display opens on a secondary monitor.
- Stage display can use a different monitor.
- Selecting Preview does not affect Audience.
- GO LIVE updates Audience immediately.
- Black Screen, Clear Text, Logo and Escape work.
- Output can be closed and reopened.
- Backup can be exported and restored.
- Core works with network disconnected.
- Missing optional AI tools do not create blocking errors.
- Verify the installer on a clean Windows 10/11 VM.
- Code-sign production installers before wide distribution to reduce SmartScreen warnings.
